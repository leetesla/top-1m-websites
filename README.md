# Top 1M Websites — Selected TLDs (October 2026)

A reproducible subset of the **Chrome UX Report (CrUX) global top 1 million web origins**, restricted to 12 TLDs:

`.com`, `.net`, `.org`, `.co`, `.io`, `.online`, `.app`, `.xyz`, `.me`, `.ai`, `.pro`, `.gg`.

**Snapshot:** 2026-10 (`202610`). **Selected:** 510,962 origin records (51.0962% of 1,000,000 input records).

## Files

- `data/202610.csv` — all selected records (`origin,rank`), preserving source order and ranking buckets.
- `data/202610.csv.gz` — compressed copy of the same filtered CSV.
- `data/top-1000.csv` — selected origins from the top-1,000 bucket (593 rows).
- `data/tld-counts.csv` — breakdown by TLD.

These data files are generated by `scripts/build.py` and published by the GitHub Actions workflow. If they do not appear yet, check the workflow run under **Actions**.

## Methodology

1. Read each `origin,rank` row from the October 2026 global CrUX top-sites snapshot.
2. Parse the hostname from `origin`, take only the **last DNS label** (the TLD), and retain rows matching the 12 allowed suffixes.
3. Do **not** apply public-suffix rules: `example.co.uk` is treated as `.uk` and excluded. Keep `www`, subdomains, schemes, and multiple origins as separate rows; no website/brand deduplication.
4. Preserve CrUX `rank` buckets. **They are not exact ordinal ranks**: websites in the same bucket have no specified order.

The original data covers web **origins**, not distinct companies, domains, or verified real-world website brands. This dataset is **not** a list of globally known or mainstream sites; that categorization needs a separate process.

## Rebuild

```sh
python3 scripts/build.py
```

The script fetches the exact upstream snapshot, verifies its SHA-256, filters the 12 TLDs, validates counts, and writes the datasets. To use a locally available source:

```sh
python3 scripts/build.py --source /path/to/202610.csv.gz
```
